Adding New Years and Sessions

Aptitude Solution Template

1 Update Year Summary

Locate the \BeginYear block for your target year. You need to update the session count in the header and add a row to the branch table.

File: main_s_aptitude.tex
\BeginYear{2011}{2 Sessions\quad·\quad Solutions}{%
  \renewcommand{\arraystretch}{1.5}
  \begin{tabularx}{\textwidth}{l X}
    \rowcolor{SoftGray}\textbf{Session} & \textbf{Participating Branches}\\\midrule
    Session 1 & All Branches \\
    Session 2 & All Branches \\
  \bottomrule
  \end{tabularx}
}

2 Add Sessions in a Year

Insert the \YearSolSession macro. This registers the session folder and tells the system where to look for the sol.tex file.

  \YearSolSession{2011/Session1}{Session : 1}{Forenoon}{05/02/11}
  \YearSolSession{2011/Session2}{Session : 2}{Afternoon}{06/02/11}
\EndYear

Parameter Reference

Argument Example Purpose
{folder} 2011/Session2 Path to the folder containing sol.tex and img/
{label} Session : 2 The text displayed in the header divider.
{slot} Afternoon Time slot (Forenoon/Afternoon/Combined).
{date} 06/02/11 The specific date or year for that session.

3 Folder Structure & sol.tex

You must create the physical directory on your computer so the images and solutions have a home.

Terminal / File Explorer
# Create the directory and image subfolder
 2011/Session2/img

Then, create a new file at 2011/Session2/sol.tex using this template:

% ============================================================
%  2011/Session2/sol.tex
% ============================================================

\MCQSol{2011}{1}{1}{A}{Easy}{https://video.link}{%
  Explanation for Question 1 goes here...
}

Auto-QID Logic

The system generates IDs automatically based on your structure. For 2011, Session 2, Question 5, the QID will be:

Q11.2.5
  • 11: Taken from the last two digits of \BeginYear{2011}
  • 2: Taken from the session sequence (the 2nd \YearSolSession call)
  • 5: Taken from your \MCQSol argument.
