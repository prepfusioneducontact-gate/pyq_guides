PrepFusion LaTeX Guide: Adding Years & Sessions in Questions Template

This documentation explains how to structure the main file for the General Aptitude PYQ Book. Follow these instructions when adding a new year of Previous Year Questions (PYQs) to the project.

1. The Basic Template

To add a new year (e.g., 2025), copy and paste the following block into your main.tex file inside the \mainmatter section. Update the values as needed.

% Example Year 2025
\BeginYear{2025}{2 Sessions\quad·\quad20 Questions}{
  \renewcommand{\arraystretch}{1.5}
  \begin{tabularx}{\textwidth}{l X c}
    \rowcolor{SoftGray} \textbf{Session} & \textbf{Participating Branches} & \textbf{Total Qs} \\ \midrule
    Session 1 & EC, EE, IN, CS, ME, CE & 10 \\
    Session 2 & XE, BT, CH, PI, TF & 10 \\ \bottomrule
  \end{tabularx}
}
  % \YearSession now takes 4 parameters: {Folder}{Name}{Time}{Date}
  \YearSession{2025/Session1}{Session : 1}{Forenoon}{10/02/25}
  \YearSession{2025/Session2}{Session : 2}{Afternoon}{11/02/25}
\EndYear

2. Command Breakdown

\BeginYear{Param 1}{Param 2}{Param 3}

This command creates the large title page for the Year and sets up the Summary Table.

Parameter What it is Example
Param 1 The Year (must be 4 digits) 2025
Param 2 Subtitle / Stats string 2 Sessions\quad·\quad20 Questions
Param 3 The Summary Table Code The entire \begin{tabularx}...\end{tabularx} block. Update the rows inside to match the actual sessions and branches for that year.

\YearSession{Param 1}{Param 2}{Param 3}{Param 4}

This command creates the visual banner for the session and automatically imports the questions for that session.

Parameter What it is Example
Param 1 The Folder Path 2025/Session1
Param 2 Session Display Name Session : 1
Param 3 Time/Shift Forenoon or Afternoon
Param 4 Date of the Exam 10/02/25
⚠️ CRITICAL FOLDER STRUCTURE REQUIREMENT:
Because of how \YearSession is programmed, whatever folder path you put in Param 1 MUST contain a file named common.tex.

For example, if you write \YearSession{2025/Session1}{...}, the LaTeX compiler will look for a file exactly at: 2025/Session1/common.tex. All your MCQ/NAT/MSQ questions for this session must go inside that common.tex file!

\EndYear

You must place this at the very end of your year block. It does two critical things:

  • Closes out the year chapter formatting.
  • Automatically generates and prints the Answer Key for all the sessions you just listed. If you forget this, the answer key won't print!

3. Working with Images

When you use the \QuestionFigure{filename} command inside your common.tex files, the system will automatically look for images in an img/ folder inside the current session folder.

Example: If you are working in 2025/Session1/common.tex, the command \QuestionFigure{q1.png} will look for the image at 2025/Session1/img/q1.png.
