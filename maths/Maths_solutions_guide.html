1. Global Book Metadata

To switch the project from "Network Theory" to "Engineering Mathematics," update the metadata block in main.tex.

% Locate these commands in main.tex
\newcommand{\BookTitle}{Engineering Mathematics}
\newcommand{\BookSubtitle}{Detailed Solutions — Topic Wise}
\newcommand{\WebsiteText}{www.PrepFusion.in}

2. Managing Math Chapters

Use \ChapterSolutionsWithBranches to link a new topic (e.g., Linear Algebra). Ensure the chapter folder matches the path provided.

\ChapterSolutionsWithBranches{chapters/ch1_linear_algebra}
  {Engineering Mathematics}  % Subject Name
  {Linear Algebra}           % Chapter Name
  {\begin{enumerate}         % Syllabus List
    \item Determinants and Matrices
    \item Systems of Linear Equations
    \item Eigenvalues and Eigenvectors
  \end{enumerate}}

3. Directory Requirements

The system iterates through \SelectedBranches and looks for files with the sol_ prefix inside your chapter folder[cite: 3].

📁 chapters/ch1_linear_algebra/
├── 📄 common.tex     (Contains \ChapterDivider)
├── 📄 sol_EC.tex     (Maths solutions for ECE)
├── 📄 sol_EE.tex     (Maths solutions for EE)
└── 📁 img/           (Chapter diagrams)
