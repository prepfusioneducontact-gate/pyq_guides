Managing Chapters and Branch-wise Question Banks

1. Changing Chapter Information

All chapter metadata is controlled by the \ChapterWithBranches command in your main .tex file.

\ChapterWithBranches{folder_path}{Subject}{Chapter Name}{Syllabus Items}

Example Change:

% Change from "Linear Algebra" to "Advanced Matrices"
\ChapterWithBranches{chapters/ch1_linear_algebra}
  {Engineering Mathematics}
  {Advanced Matrices} % <-- Edit this line
  {\begin{enumerate}
    \item Eigenvalues and Eigenvectors
    \item Cayley-Hamilton Theorem
  \end{enumerate}}

2. Folder Structure for Branch Questions

The system automatically looks for specific .tex files inside the chapter folder based on the \SelectedBranches list.

📁 chapters/ch1_linear_algebra/
├── 📄 common.tex      # Shared content for all branches
├── 📄 EC.tex          # Questions for ECE branch
├── 📄 EE.tex          # Questions for Electrical branch
└── 📁 img/
    └── 📁 EC/         # Images used in EC.tex

3. Adding Branch-wise Questions

To add questions for a specific branch (e.g., ME), create ME.tex in the chapter folder and use the standard question macros.

% Inside chapters/ch1_linear_algebra/ME.tex

\MCQ{Unique_ID}{Year}{Session}{Marks}{Question Body}{Correct_Ans}{
  Explanation text...
}

% For images, the system automatically looks in: 
% img/[BRANCH_CODE]/filename
\QuestionFigure[0.8\columnwidth]{matrix_diagram.png}
Pro Tip: The Unique_ID is mapped to the Answer Key automatically. Ensure it follows the numbering sequence of that branch.
